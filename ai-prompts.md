# AI Prompts

Here is a list of the prompts given to the AI to make this project.

## ONE

`/plan` create a macos swift project that reads shapes from a json data file as square, circle, rectangle, triangle, etc. Then it will create nodes on the game kit screen from those shapes. the nodes will be a variable size of many pixels. a node is always a square like 32 by 32 pixels, or as small as 4 by 4 pixels. the arrangement of nodes will be called a map. then the swift project will read from another set of json data files that describe transitions of colors over time, these are called mood files. the nodes in the map will use these json files to animate color transitions in various patterns such as top down, inside out, left to right and whatever other patterns gemini decides. the program will take keyboard input of left arrow and right arrow to change the map file. up arrow and down arrow keyboard input will change the mood file. as the file is changed, the program will transition the current map and color animation into a new one.


## TWO

add an xcode project file that will load all the files

## THREE

add to the program the ability to dynamically change the node size by pressing the + or - button
